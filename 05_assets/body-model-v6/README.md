- GARANG rendering: equal-weight Caucasian/African/Asian young gender macro shape, orthographic FRONT/SIDE/BACK projection, back-face culling, painter-depth ordering, restrained neutral shading.

The dense mesh SVGs are visual-only. GARANG muscle selection/highlighting remains a separate interaction layer in `garang-polish-v3.js`, so visual fidelity can evolve independently from product behavior.
