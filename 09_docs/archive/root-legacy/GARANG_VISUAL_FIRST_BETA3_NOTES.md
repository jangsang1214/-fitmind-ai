# GARANG 0.11.0-beta.3 — Visual-First Commercial UX Refinement

Base: 0.11.0-beta.2

## Changed
- TODAY: human-body-first visual status, compact GARANG Score/decision, visual check-in meters, visual quick log cards.
- LOG: visual-first workout/nutrition/running/body entry cards; Settings/Profile access kept visible.
- WORKOUT: front/back body map moved to the primary position, muscle-region filters, visual exercise library, mini muscle figures in history.
- NUTRITION: camera-first flow retained and page copy reduced.
- SETTINGS: language, units, FREE/PRO, cloud sync, export/import, logout preserved as first-class settings.
- Existing certification overlay runtime intentionally unchanged. Overlay redesign is not included in this package per product direction.

## Product rule
GARANG should be understood by sight before it is read: body first for workout, food image first for nutrition, metrics before explanations, details progressively disclosed.
