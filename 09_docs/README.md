# GARANG Product Documentation

The current public product and architecture overview is maintained in the repository root [`README.md`](../README.md).

This directory contains supporting product, QA and historical documentation. Older documents may describe the state of the product at the time they were written; they should not be treated as evidence for the current runtime, release status or production AI configuration without checking the current repository and CI.

Current implementation facts are owned by the PRODUCT repository code and tests. Durable cross-repository project state, decisions and release reconciliation are maintained in the GARANG CONTROL repository.
