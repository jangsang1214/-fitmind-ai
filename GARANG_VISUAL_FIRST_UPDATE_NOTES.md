# GARANG 0.11.0-beta.2 — Visual First Update

## Product decision
GARANG should not compete by putting more explanatory Korean text on screen. The primary workout and nutrition flows now prioritize visual recognition, next action, and essential metrics.

## Workout
- Added original front/back anatomical body visual.
- Exercise selection highlights the primary trained region.
- Current session shows only exercise count, volume, and calories at hero level.
- Detailed set/reps/weight inputs remain available below the visual.
- Recent records include visual muscle cues.

## Nutrition
- Camera/Meal Scan is now the primary entry point.
- Calories and P/C/F are visible as compact visual metrics.
- Manual food entry remains available but is collapsed under a secondary disclosure.
- Vision results remain drafts until user confirmation.

## Settings
- Restored a dedicated Settings entry in the top bar.
- Restored language selection (Korean/English preference).
- Restored metric/imperial display preference storage.
- Restored FREE / PRO comparison and current plan status.
- No fake PRO activation is provided before a real payment provider exists.
- Cloud retry / export / legacy import / logout are available from Settings.

## Brand direction
- Current Korean premium palette is preserved.
- Visual references are treated as category conventions, not copied proprietary layouts or assets.
- The design principle is Korean restraint: empty space, low saturation, precise hierarchy, minimal ornament.

## Explicitly excluded
Workout/Running transparent certification overlay redesign is intentionally excluded from source in this build per product-owner request. It should be designed/reviewed separately before implementation.
