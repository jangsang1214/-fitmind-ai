GARANG V8.5.1 — Modern Workout Certification

Added a minimal, modern 9:16 workout certification component designed to keep
the user's workout photo as the hero and GARANG as a small supporting layer.

Features:
- 9:16 story-friendly composition
- Small GARANG mark and date
- Exercise name
- Sets
- Total volume
- PR indicator
- Set details (weight x reps)
- Optional monochrome mode
- Subtle glass stats instead of a large opaque card
- Reusable JS renderer: window.GARANGWorkoutCert.render(target, data)

The existing V8.5 files were preserved; the new CSS/JS is additive.
